# 별결 타로

네이비와 은은한 금색으로 구성한 모바일·PC용 타로 웹사이트입니다. 배열의 모양과 장수를 먼저 고르고 질문을 적은 뒤, 카드를 섞고 직접 선택해 풀이를 읽습니다.

[사이트 열기](https://glasscola.github.io/tarot-/)

## 주요 기능

- 6가지 배열과 배치 그림: 한 장의 조언, 과거·현재·미래, 상황·행동·흐름, 십자 5장, 두 갈래 5장, 삼각형 3장.
- 질문에 어울리는 배열 안내와 카드의 놓는 순서·자리 의미 설명.
- 가로 넘김 없는 전체 78장 격자, 메이저 22장 모드, 역방향 선택.
- 셔플·선택·이동 모션과 필요한 장수를 모두 고른 뒤 한 장씩 공개하는 흐름.
- 카드·배열 위치·주제에 맞춘 해설, 생일 카드 계산과 계산 과정.
- 현재 브라우저에 기록 저장, 결과 복사·공유와 질문 숨기기.

외부 AI나 API 키 없이 실행됩니다. 해설은 미리 작성한 내용을 카드와 자리의 의미에 맞춰 조합합니다. 질문 문장에서 사실을 추론하거나 미래를 확정하는 서비스는 아닙니다. 십자·두 갈래·관계 배열은 앱에서 구성한 자리 의미를 안내합니다.

## 로컬 실행

저장소 폴더에서 Python 3으로 개발 서버를 실행합니다.

```sh
python -m http.server 8080
```

브라우저에서 [http://localhost:8080](http://localhost:8080)을 엽니다. 설치하거나 빌드할 패키지는 없습니다. JavaScript 모듈을 사용하므로 `index.html`을 파일 주소로 직접 열기보다 HTTP 서버로 실행하세요.

## 검증

Node.js가 설치되어 있으면 다음 명령으로 엔진을 검증할 수 있습니다. CI에서는 Node.js 24를 사용합니다.

```sh
npm test
```

78장 덱의 무결성, 셔플, 6가지 배열의 배치와 자리 순서, 기존 기록 호환, 생일 계산, 풀이 조합, 질문 숨기기와 텍스트 복사를 검사합니다. 모바일 화면과 모션은 브라우저에서도 확인해야 합니다.

## 배포와 기록

[DEPLOYMENT.md](DEPLOYMENT.md)에 GitHub Pages 설정과 업데이트 방법을 정리했습니다. 기록은 현재 브라우저의 저장소에 남으며 로그인이나 기기 간 동기화 기능은 없습니다. 도메인·프로토콜·포트가 바뀌면 별도의 저장 공간을 사용하므로 로컬 실행 기록이 배포 사이트로 자동 이동하지 않습니다.

## 이미지와 출처

카드 이미지는 Pamela Colman Smith의 1909년 Rider–Waite–Smith 카드(Roses & Lilies) 원본 스캔을 사용합니다. 포함된 이미지별 Wikimedia Commons 원본 페이지, 퍼블릭 도메인 표시, 스캔 크레딧과 가공 내역은 [assets/sources.json](assets/sources.json)에 있습니다. 출처 정보를 함께 유지하세요. 현대 재채색판이나 다른 덱에 같은 이용 조건을 적용하지 마세요.

제공된 책의 문장·고유 해설·한국식 카드 이미지는 포함하지 않습니다. 코드와 앱 설명문에는 별도 라이선스를 지정하지 않았으며, 카드 이미지의 출처·이용 조건은 위 파일을 기준으로 확인할 수 있습니다.
